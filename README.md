# Analysis Code and Processed Data for “Intrinsically Protected Grid States in a Superconducting Qubit”

This repository contains the numerical simulation code and processed datasets used in the manuscript:

**“Intrinsically Protected Grid States in a Superconducting Qubit”**

---

## Repository Contents

### `/code/`
Source code used for simulations and Hamiltonian diagonalization.

Requirements: install `scqubits` dependency, see `https://scqubits.readthedocs.io/en/latest/installation.html`

### `/data/`
Data files (CSV/NPZ) corresponding to the processed datasets used in the manuscript.
